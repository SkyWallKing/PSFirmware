## 1.2.0 (2026-09-25)
- Home screen widget: add PS Firmware to your home screen and resize it freely, from 1x1 up to the full card.
- Small widgets show just the minimum version, in large text, so it stays readable.
- Icon widget: a 1x1 widget that looks like an app icon, with the minimum version in large text. It lines up with your app icons, and you can fine-tune its position and size in the app (a tip shows up when you add it).
- Refresh button on the widget to check the firmware right away.
- Dynamic theme: the notification, its icon, the widget and the app turn green when the minimum version matches the latest, and red when it doesn't. The app shows an animated preview.
- What's new: after an update the app shows what changed, and you can see the changes before updating.

## 1.1.0 (2026-09-24)
- Automatic updates: the app checks GitHub for new versions and installs them with one tap.

## 1.0.1 (2026-09-24)
- "Last update" is now "Last API update", to make clear it's when the API data changed.

## 1.0.0 (2026-09-24)
- First release: ongoing notification with the latest and minimum PlayStation firmware for your region.
- Region picker, notification in the region's language, and updates every 5 minutes.
